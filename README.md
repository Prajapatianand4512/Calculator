# 🌟 NEXUS CALC — Next-Gen Interactive Calculator

An ultra-modern, glassmorphic, interactive, and dynamic calculator built with **HTML5, CSS3, and JavaScript (Vanilla ES6+)**.

---

## ✨ Features

- 🎨 **4 Stunning Themes**:
  - **Cyber Neon**: Deep dark obsidian with electric cyan & violet neon gradients.
  - **Aurora Glow**: Mystic emerald & teal glowing mesh gradients.
  - **Frost Light**: Clean frosted glassmorphism for daylight use.
  - **Midnight Black**: Pure OLED pitch-black aesthetic with energetic orange accents.
- ⚡ **Realtime Live Preview**: Calculates results instantly as you type before pressing equals.
- 🔬 **Expandable Scientific Keypad (Landscape Mode)**:
  - Switches smoothly from **Standard Portrait** to **Wide Landscape** side-by-side mode.
  - Zero vertical scrolling needed — height stays perfectly compact while scientific keys expand on the left!
  - Trigonometry: `sin`, `cos`, `tan`, `sin⁻¹`, `cos⁻¹`, `tan⁻¹`
  - Mode Switch: **DEG** (Degrees) ⇄ **RAD** (Radians)
  - Functions: `√` (Square Root), `xʸ` (Power), `log`, `ln`, `|x|` (Absolute), `n!` (Factorial)
  - Constants: `π` (Pi), `e` (Euler's number)
- 🔊 **Built-in Synthesizer Sound FX**:
  - Pure Web Audio API synthesized audio (zero audio file dependencies).
  - Tactile ticks, crisp tones for operators, and dual harmonic chime on equals.
  - One-click mute/unmute toggle with memory.
- 📜 **Calculation History Tape**:
  - Slide-out drawer tracking past calculations with timestamps.
  - Click any past calculation to instantly restore it into the calculator.
  - Clear history with confirmation toast.
- 📋 **Copy to Clipboard**: Quick copy button for immediate result sharing.
- ⌨️ **Full Keyboard Support**:
  - Digits `0-9`, `.`, operators `+`, `-`, `*`, `/`, `%`, `^`, `(`, `)`
  - `Enter` / `=` to calculate
  - `Backspace` to delete
  - `Escape` / `c` to clear
  - Visual button depress animation synced with physical keystrokes.
- 📱 **Fully Responsive**: Flawless experience on desktops, tablets, and smartphones.

---

## 🚀 How to Run

Simply open `index.html` in any web browser (Chrome, Edge, Firefox, Safari). No installation or server required!
